# Digital Help Studio blog

This repository holds the blog of digitalhelpstudio.com. Hostinger deploys it into
public_html/blog, so it appears at https://digitalhelpstudio.com/blog/.

Everything here is generated: every article folder, index.html, posts.json (read by the
homepage), sitemap.xml, feed.xml, and the assets/ and images/ folders.
Don't edit the files by hand. Replace them with the update package you receive.
